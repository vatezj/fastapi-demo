
# 游赚模块项目简介

## 项目概述

游赚模块是一个基于FastAPI的完整任务管理平台，支持用户发布任务、接单完成任务、获得佣金等核心功能。采用模块化架构设计，支持独立部署和系统集成。

## 核心功能

### 1. 业务功能
- **用户管理**: 用户注册、登录、邀请分销、状态管理
- **任务管理**: 任务发布、编辑、删除、状态管理、类型管理
- **订单管理**: 任务接单、状态更新、审核流程、分佣计算
- **财务管理**: 账户管理、充值提现、交易记录、分佣管理
- **地区管理**: 省市区三级地区管理、任务地区关联

### 2. 技术特性
- **权限控制**: 基于RBAC的细粒度权限管理，33个权限标识
- **操作日志**: 完整的后台操作日志记录，支持审计追溯
- **模块化架构**: 支持独立部署和系统集成
- **异步架构**: 基于FastAPI的全异步架构，支持高并发

## 技术架构

```
游赚模块 (module_yozuan)
├── 前台API接口 (面向普通用户)
├── 后台管理接口 (面向管理员)
├── 权限控制系统 (RBAC模型)
├── 操作日志系统 (完整审计)
└── 核心业务模块
    ├── 用户管理
    ├── 任务管理
    ├── 订单管理
    ├── 财务管理
    └── 系统管理
```

## 技术栈

- **后端**: FastAPI + SQLAlchemy + PostgreSQL/MySQL
- **缓存**: Redis
- **权限**: RBAC模型 + JWT认证
- **日志**: 操作日志 + 性能监控
- **部署**: Docker + 支持独立部署

## 快速开始

### 1. 独立部署
```bash
cd module_yozuan
uvicorn app:yozuan_app --host 0.0.0.0 --port 8001
```

### 2. 系统集成
```python
from module_yozuan.app import yozuan_app
app.mount("/yozuan", yozuan_app, name="yozuan_module")
```

### 3. 访问地址
- **游赚模块**: http://127.0.0.1:8001/docs
- **后台管理**: http://127.0.0.1:9099/admin/docs
